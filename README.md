# FORME 形研运动

奶油白与酸橙绿风格的普拉提、瑜伽、健身工作室网站，含可操作的预约、会员与课时管理演示。使用原生 HTML / CSS / JavaScript，无第三方前端运行依赖。

## 本地运行

需要 Node.js 20 或更新版本、npm，以及 Python 3（仅用于预览服务器）。

```sh
npm ci
npm run build
npm run dev
```

打开 http://127.0.0.1:4325 。如没有 Python，可使用任意静态 HTTP 服务器托管 `dist/`。请通过 HTTP 打开，直接双击 HTML 无法正确加载模块。

```sh
npm run check
npm test
```

构建产物在 `dist/`，可作为 Vercel 静态项目部署。构建命令 `npm run build`，输出目录 `dist`，Framework Preset 选择 Other。源码目录自身作为独立仓库根目录。`.env.example` 说明本演示无需环境变量。

## 主要体验

- 页头五个整站 Tab：首页、关于我们、课程预约、教练团队、会员中心。每次只显示对应栏目，手机顶部直接切换。
- 支持键盘方向键、Home/End、浏览器前进后退、刷新恢复栏目与旧锚点直达；跨栏选课自动定位课表。
- 会员功能直接内嵌于会员栏目，预约成功后可以直接查看记录。
- 课程重点、小班/私教对比、示例教练简介、常见问题；课表与预约保持直接可见。
- 北京时间未来 14 天课表，类型/教练/日期筛选，满班禁用、重复预约和时间重叠校验。
- 体验预约与常规预约；初始 12 演示课时，常规课预扣 1、取消返还，模拟签到不重复扣课时。每个本地演示会员限一节有效体验课。
- 会员中心查看记录、课时流水、导出 JSON、再次确认后清空。跨标签页同步与存储失败提醒。
- 响应式布局、原生可关闭对话框、键盘导航、免费源码小红书原始二维码入口。

## 演示范围与数据

品牌、教练、价格与席位为虚构示例，工作室影像与 logo 由 AI 生成，提示词见 ASSET-PROMPTS.md。教练采用字母示意头像，不代表真实人物或资质。体验课 ¥99 仅为价格示例，不收费。

这不是接入了真实工作室的服务。预约只保存到当前浏览器的 `localStorage`，键名 `forme.studio.demo.v1`；同一浏览器里的所有访问者共享此演示账户。没有注册/认证、支付、短信、邮件、真实预约投递、云端库存或跨设备同步。请填写演示称呼，不填敏感信息。

普通预约和签到只是本地状态变更，不能证明真实到店或真实扣费；「模拟签到」允许提前操作以演示完整流程。取消未签到预约返还 1 课时。体验取消后可重约，已经签到的体验不能再次领取。存储被禁用、异常或写入失败时仅在页面内临时保存并明确提示，刷新可能丢失；可以导出备份。

生产化需要自行实现服务端认证、会员权限、数据存储、排课与库存的并发事务、支付与退款、通知、隐私和运营政策，并重新核对商业部署条件；本项目未连接这些服务。当前无需后台 API 或密钥。
